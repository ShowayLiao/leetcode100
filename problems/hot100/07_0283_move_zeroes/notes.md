# 解题笔记

## 思路提示

维护一个指针，表示下一个非零元素应该放置的位置。扫描数组时遇到非零元素就保留其顺序并向前填充，扫描结束后将剩余位置补为 `0`。

## 原地修改数组

Python 的 `list` 是可变对象，可以通过下标赋值直接修改原数组。不要写成 `nums = 新列表`，因为这只是让变量指向了新列表；如果要求保持原列表对象，应修改 `nums[i]`，或使用 `nums[:] = ...`。

这道题使用 `write` 和 `read` 两个指针：

- `read` 扫描数组，寻找非零元素；
- `write` 指向下一个非零元素应该放置的位置；
- 把非零元素写到 `nums[write]`，然后让 `write` 向后移动。

## 将目标元素移动到数组末尾

以“移动 `0` 到末尾”为例，不必逐个搬动 `0`。先把所有非零元素按原顺序写到数组前面，再把剩余位置全部填成 `0`：

```python
write = 0

for read in range(len(nums)):
    if nums[read] != 0:
        nums[write] = nums[read]
        write += 1

for i in range(write, len(nums)):
    nums[i] = 0
```

这样非零元素会保持相对顺序，数组后半部分自然全部变成 `0`。整个过程时间复杂度为 `O(n)`，额外空间复杂度为 `O(1)`。

也可以在发现非零元素时与 `write` 位置交换：

```python
if nums[read] != 0:
    nums[write], nums[read] = nums[read], nums[write]
    write += 1
```

## 需要保持的不变量

- 已处理区间中的非零元素顺序与原数组一致。
- 写入指针之前的位置不会再出现未处理的非零元素。
- 不能只排序或交换零，否则可能破坏非零元素的相对顺序。

## 复杂度目标

- 时间复杂度：`O(n)`。
- 额外空间复杂度：`O(1)`，不计输入数组本身。

## 错误与边界

检查数组无零、全为零、零出现在开头或末尾，以及 `n = 0` 时的处理。输出必须保留所有元素，包括零的数量。
