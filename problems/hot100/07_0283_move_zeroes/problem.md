# LeetCode Hot 100 07 - 移动零

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 283. 移动零](https://leetcode.cn/problems/move-zeroes/)
- 难度：简单
- 标签：数组、双指针
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个整数数组，将数组中的所有 `0` 移动到数组末尾，同时保持所有非零元素的相对顺序不变。要求在原数组上完成调整；本地练习只需输出调整后的数组。

## 输入描述

- 第一行输入整数 `n`，表示数组长度。
- 第二行输入 `n` 个整数，表示数组元素。

## 输出描述

输出调整后的数组，元素之间使用一个空格分隔。非零元素应保持原有相对顺序，所有 `0` 位于末尾。

## 数据范围

- `0 <= n <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 样例

输入：

```text
8
0 1 0 3 12 0 4 0
```

输出：

```text
1 3 12 4 0 0 0 0
```
