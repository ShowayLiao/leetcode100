## Local input contract

第一行输入 n、p、q；第二行输入 n 个按层序排列的节点值，空节点写为 null。p 和 q 一定存在且值唯一。

## Local output contract

输出节点 p 与 q 的最近公共祖先的值。

## Constraints

- 1 <= n <= 10^4。

## Example

Input:
```text
11 5 1
3 5 1 6 2 0 8 null null 7 4
```

Output:
```text
3
```
