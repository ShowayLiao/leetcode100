# LeetCode Hot 100 36 - 二叉搜索树中第 K 小的元素

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 230. 二叉搜索树中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)
- Difficulty: 中等
- Tags: 二叉树、二叉搜索树、中序遍历
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n 和 k；第二行输入 n 个按层序排列的节点值，空节点写为 null。节点值互不相同。

## Local output contract

输出二叉搜索树中第 k 小的节点值。

## Constraints

- 1 <= n <= 10^4；1 <= k <= n。

## Example

Input:
```text
7 3
5 3 6 2 4 null 7
```

Output:
```text
4
```
