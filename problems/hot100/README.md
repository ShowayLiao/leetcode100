# LeetCode Hot 100

这里保存未指定其他来源时默认新增的 Hot 100 题目，与历史上的 `problems/leetcode/` 目录分开管理。

题目目录使用“内部做题顺序 + 四位真实题号 + slug”命名，例如：

```text
problems/hot100/01_0001_two_sum/
```

每道题包含：

```text
problem.md
main.py
notes.md
tests/
```

Hot 100 的范围、顺序、进度和本地链接统一维护在 [`sets/leetcode_hot100.md`](../../sets/leetcode_hot100.md)。
