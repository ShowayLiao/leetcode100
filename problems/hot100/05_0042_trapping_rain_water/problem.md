# LeetCode Hot 100 05：接雨水

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)
- 难度：困难
- 标签：数组、双指针、动态规划、单调栈
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一排表示柱高的非负整数。相邻柱子宽度均为 1，降雨后柱子之间可以积水。请计算这些柱子最多能够接住的雨水总量。

每个位置能积累的水量取决于它左侧和右侧的最高柱子，并且不能为负数。

## 输入描述

- 第一行一个整数 `n`，表示柱子数量。
- 第二行 `n` 个非负整数 `height_i`，表示从左到右的柱高。

当 `n = 0` 时，第二行可以为空；本地测试中的输入仍会保留第二行换行。

## 输出描述

输出一个整数，表示最多能接住的雨水总量。

## 数据范围

- `0 <= n <= 2 * 10^4`
- `0 <= height_i <= 10^5`
- 结果使用 Python 整数计算，不需要取模。

## 样例

输入：

```text
12
0 1 0 2 1 0 1 3 2 1 2 1
```

输出：

```text
6
```
