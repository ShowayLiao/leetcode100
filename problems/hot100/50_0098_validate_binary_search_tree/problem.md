- Tags: 二叉树、二叉搜索树、中序遍历

## Local input contract

第一行输入 n；第二行输入 n 个按层序排列的节点值，空节点写为 null。

## Local output contract

如果给定二叉树满足二叉搜索树定义，输出 true，否则输出 false。

## Constraints

- 0 <= n <= 10^4；节点值为整数。

## Example

Input:
```text
7
5 1 4 null null 3 6
```

Output:
```text
false
```
