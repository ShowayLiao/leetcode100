# LeetCode Hot 100 06：盛最多水的容器

> 状态：练习中：运行错误。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)
- 难度：中等
- 标签：数组、双指针、贪心
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一排竖直线段的高度。任选两条线段，与横轴共同形成一个容器；容器宽度是两条线段的下标距离，高度取两条线段中较矮者。请计算所有选择中能够容纳的最大面积。

## 输入描述

- 第一行一个整数 `n`，表示线段数量。
- 第二行 `n` 个非负整数 `height_i`，表示从左到右的线段高度。

## 输出描述

输出一个整数，表示最大容积（面积）。

## 数据范围

- `2 <= n <= 10^5`
- `0 <= height_i <= 10^4`
- 结果使用 Python 整数计算，不需要取模。

## 样例

输入：

```text
9
1 8 6 2 5 4 8 3 7
```

输出：

```text
49
```
