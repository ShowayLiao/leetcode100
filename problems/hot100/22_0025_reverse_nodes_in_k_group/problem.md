# LeetCode Hot 100 22 - K 个一组翻转链表

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 25. K 个一组翻转链表](https://leetcode.cn/problems/reverse-nodes-in-k-group/)
- Difficulty: 困难
- Tags: 链表、分组反转
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n 和 k；第二行输入 n 个节点值，按链表顺序排列。

## Local output contract

输出处理后链表的节点值，以空格分隔；不足 k 个的尾部保持原顺序。

## Constraints

- 1 <= n <= 5000；1 <= k <= n；节点值为整数。

## Example

Input:
```text
5 2
1 2 3 4 5
```

Output:
```text
2 1 4 3 5
```
