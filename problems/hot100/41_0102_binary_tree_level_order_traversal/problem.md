- Source: [LeetCode 102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)
- Difficulty: 中等
- Tags: 二叉树、广度优先搜索、队列
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个按层序排列的节点值，空节点写为 null。

## Local output contract

按层输出节点值，每层占一行，层内节点以空格分隔。

## Constraints

- 0 <= n <= 2 * 10^4。

## Example

Input:
```text
7
1 2 3 4 5 null 7
```

Output:
```text
1
2 3
4 5 7
```
