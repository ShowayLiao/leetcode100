# LeetCode Hot 100 24 - 两两交换链表中的节点

> 状态：未实现。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 24. 两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)
- Difficulty: 中等
- Tags: 链表
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个节点值。n 为 0 时第二行可为空。

## Local output contract

输出交换相邻节点后的值序列，以空格分隔；空链表输出 empty。

## Constraints

- 0 <= n <= 10000；节点值为整数。

## Example

Input:
```text
4
1 2 3 4
```

Output:
```text
2 1 4 3
```
