# LeetCode Hot 100 26 - 删除链表的倒数第 N 个结点

- Source: [LeetCode 19. 删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)
- Difficulty: 中等
- Tags: 链表、双指针
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入链表长度 m 和要删除的倒数序号 n；第二行输入 m 个节点值。

## Local output contract

输出删除后链表的值序列，以空格分隔；空链表输出 empty。

## Constraints

- 1 <= n <= m <= 10000；节点值为整数。

## Example

Input:
```text
5 2
1 2 3 4 5
```

Output:
```text
1 2 3 5
```
