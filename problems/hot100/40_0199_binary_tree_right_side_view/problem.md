## Local input contract

第一行输入 n；第二行输入 n 个按层序排列的节点值，空节点写为 null。

## Local output contract

从上到下输出二叉树每一层最右侧可见的节点值。

## Constraints

- 0 <= n <= 10^4。

## Example

Input:
```text
5
1 2 3 null 4
```

Output:
```text
1 3 4
```
