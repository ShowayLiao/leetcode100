# LeetCode Hot 100 25 - 两数相加

> 状态：未实现。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 2. 两数相加](https://leetcode.cn/problems/add-two-numbers/)
- Difficulty: 中等
- Tags: 链表、模拟
- Local mode: ACM-style standard input and output

## Local input contract

依次输入两个链表：每个链表先输入一行长度，再输入一行节点值。每个节点是一位数字，低位在前。

## Local output contract

输出和的各位数字，低位在前，以空格分隔。

## Constraints

- 两条链表均非空，长度各不超过 10000；数字为 0 到 9；除数字 0 外无多余前导零。

## Example

Input:
```text
3
2 4 3
3
5 6 4
```

Output:
```text
7 0 8
```
