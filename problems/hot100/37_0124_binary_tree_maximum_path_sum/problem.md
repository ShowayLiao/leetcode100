> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

- Tags: 二叉树、深度优先搜索、动态规划
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个按层序排列的节点值，空节点写为 null。

## Local output contract

输出二叉树中任意两点之间一条路径的最大节点值之和。

## Constraints

- 1 <= n <= 3 * 10^4；节点值为整数。

## Example

Input:
```text
7
-10 9 20 null null 15 7
```

Output:
```text
42
```
