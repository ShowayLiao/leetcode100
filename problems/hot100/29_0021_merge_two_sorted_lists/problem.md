# LeetCode Hot 100 29 - 合并两个有序链表

> 状态：未实现。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)
- Difficulty: 简单
- Tags: 链表、归并
- Local mode: ACM-style standard input and output

## Local input contract

依次输入两个链表：每条先输入一行长度，再输入一行升序节点值。空链表的值行可为空。

## Local output contract

输出合并后的升序节点值，以空格分隔；空链表输出 empty。

## Constraints

- 两条链表的长度均不超过 10000；节点值为整数。

## Example

Input:
```text
3
1 2 4
3
1 3 4
```

Output:
```text
1 1 2 3 4 4
```
