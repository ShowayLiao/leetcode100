> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 114. 二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)

- Tags: 二叉树、深度优先搜索、链表
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个按层序排列的节点值，空节点写为 null。

## Local output contract

按照先序遍历顺序输出展开后链表中的节点值。

## Constraints

- 0 <= n <= 2 * 10^4。

## Example

Input:
```text
6
1 2 5 3 4 null 6
```

Output:
```text
1 2 3 4 5 6
```
