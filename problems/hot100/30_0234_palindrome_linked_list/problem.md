# LeetCode Hot 100 30 - 回文链表

> 状态：未实现。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 234. 回文链表](https://leetcode.cn/problems/palindrome-linked-list/)
- Difficulty: 简单
- Tags: 链表、双指针
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个节点值。n 为 0 时第二行可为空。

## Local output contract

若从头到尾的节点值序列为回文，输出 true，否则输出 false。

## Constraints

- 0 <= n <= 10000；节点值为整数。

## Example

Input:
```text
4
1 2 2 1
```

Output:
```text
true
```
