# LeetCode Hot 100 09 - 无重复字符的最长子串

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)
- 难度：中等
- 标签：哈希表、字符串、滑动窗口
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个字符串 `s`，请找出其中不包含重复字符的最长连续子串，输出该子串的长度。

子串必须连续，空格也属于字符串内容。

## 输入描述

输入一行字符串 `s`。整行内容都属于字符串，行中的空格不能忽略；空行表示空字符串。

## 输出描述

输出一个整数，表示最长无重复连续子串的长度。

## 数据范围

- `0 <= |s| <= 5 * 10^4`。
- `s` 由英文大小写字母、数字、符号和空格组成。

## 样例

输入：

```text
abcabcbb
```

输出：

```text
3
```
