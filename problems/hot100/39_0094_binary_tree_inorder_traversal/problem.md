# LeetCode Hot 100 39 - 二叉树的中序遍历

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)
- Difficulty: 简单
- Tags: 二叉树、栈、遍历
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个按层序排列的节点值，空节点写为 null。

## Local output contract

按中序遍历顺序输出节点值，空树输出空行。

## Constraints

- 0 <= n <= 10^4。

## Example

Input:
```text
5
1 2 3 null 4
```

Output:
```text
2 4 1 3
```
