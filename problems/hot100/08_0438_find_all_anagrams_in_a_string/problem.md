# LeetCode Hot 100 08 - 找到字符串中所有字母异位词

> 状态：练习中：运行错误。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)
- 难度：中等
- 标签：哈希表、字符串、滑动窗口
- 本地模式：ACM 标准输入输出

## 题目摘要

给定文本串 `s` 和非空模式串 `p`，找出 `s` 中与 `p` 字母组成和出现次数完全相同的连续子串，并输出这些子串的起始下标。结果按下标升序排列。

## 输入描述

- 第一行输入文本串 `s`。
- 第二行输入非空模式串 `p`。
- 本地数据使用小写英文字母，不包含额外空格。

## 输出描述

- 第一行输出匹配起点的数量。
- 如果存在匹配，第二行按升序输出所有起点下标，元素之间使用一个空格分隔。
- 如果不存在匹配，只输出一行 `0`。

## 数据范围

- `1 <= len(p) <= len(s) <= 3 * 10^4`
- `s` 和 `p` 只包含小写英文字母。

## 样例

输入：

```text
cbaebabacd
abc
```

输出：

```text
2
0 6
```
