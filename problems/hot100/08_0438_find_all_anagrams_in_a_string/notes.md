# 解题笔记

## 思路提示

使用固定长度为 `len(p)` 的滑动窗口。维护模式串与当前窗口的字符频次；窗口每次右移一格时加入新字符并移除最左字符，频次完全相同时记录窗口左端点。

## 需要保持的不变量

- 每次比较时，窗口长度始终等于 `len(p)`。
- 窗口频次与模式频次相同，当且仅当该窗口是字母异位词。
- 每个窗口只检查一次，因此重叠匹配不能被跳过。

## 复杂度目标

- 时间复杂度：`O(len(s))`。
- 额外空间复杂度：`O(1)`；字符集固定为 26 个小写字母。

## 错误与边界

注意模式串长度等于文本串、匹配窗口重叠、完全没有匹配，以及模式串中存在重复字符的情况。无结果时不能输出第二行下标。
