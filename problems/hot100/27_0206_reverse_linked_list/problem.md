# LeetCode Hot 100 27 - 反转链表

> 状态：未实现。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/)
- Difficulty: 简单
- Tags: 链表
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个节点值。n 为 0 时第二行可为空。

## Local output contract

输出反转后链表的节点值，以空格分隔；空链表输出 empty。

## Constraints

- 0 <= n <= 10000；节点值为整数。

## Example

Input:
```text
5
1 2 3 4 5
```

Output:
```text
5 4 3 2 1
```
