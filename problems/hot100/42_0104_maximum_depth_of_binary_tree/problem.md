> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- Source: [LeetCode 104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

- Tags: 二叉树、深度优先搜索、广度优先搜索
- Local mode: ACM-style standard input and output

## Local input contract

第一行输入 n；第二行输入 n 个按层序排列的节点值，空节点写为 null。

## Local output contract

输出二叉树的最大深度，空树深度为 0。

## Constraints

- 0 <= n <= 10^4。

## Example

Input:
```text
7
3 9 20 null null 15 7
```

Output:
```text
3
```
