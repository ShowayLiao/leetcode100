# 2. 两数相加

- 来源：[LeetCode 2. 两数相加](https://leetcode.cn/problems/add-two-numbers/)
- 难度：中等
- 标签：链表、数学、递归
- 本地模式：ACM 标准输入输出

## 题目摘要

给定两个非空链表，链表中的每个节点保存一个数字，并且数字按照从低位到高位的逆序排列。请将两个链表表示的非负整数相加，并输出表示结果的链表。

## 输入描述

第一行包含两个整数 `n1` 和 `n2`，分别表示两个链表的长度。

第二行包含 `n1` 个整数，表示第一个链表从头节点到尾节点的数字。第三行包含 `n2` 个整数，表示第二个链表从头节点到尾节点的数字。每个数字都在 `0` 到 `9` 之间。

链表顺序与题目一致：输入序列的第一个数字是个位。

## 输出描述

第一行输出结果链表的长度 `k`。第二行输出 `k` 个整数，表示结果链表从头节点到尾节点的数字，数字之间用空格分隔。

## 数据范围

- `1 <= n1, n2 <= 100`
- `0 <= digit <= 9`
- 除数字 `0` 外，两个数都不包含前导零。

## 示例

输入：

```text
3 3
2 4 3
5 6 4
```

输出：

```text
3
7 0 8
```

解释：`342 + 465 = 807`，结果链表为 `[7, 0, 8]`。
