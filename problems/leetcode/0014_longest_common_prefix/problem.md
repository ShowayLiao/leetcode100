# 14. 最长公共前缀

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 14. 最长公共前缀](https://leetcode.cn/problems/longest-common-prefix/)
- 难度：简单
- 标签：字符串
- 本地模式：ACM 标准输入输出

## 题目摘要

给定字符串数组 `strs`，找出数组中所有字符串的最长公共前缀。如果不存在公共前缀，输出空行。

## 输入描述

第一行包含整数 `n`，表示字符串数量。

接下来 `n` 行每行包含一个字符串。字符串可以为空，因此必须按行读取，不能用按空白分隔的方式读取；输入行中的换行符不属于字符串。

## 输出描述

输出所有字符串的最长公共前缀，并换行。若没有公共前缀，输出一个空行。

## 数据范围

- `1 <= n <= 200`
- `0 <= len(strs[i]) <= 200`
- 字符串只包含小写英文字母。

## 示例

输入：

```text
3
flower
flow
flight
```

输出：

```text
fl
```
