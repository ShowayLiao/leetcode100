# 5. 最长回文子串

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)
- 难度：中等
- 标签：字符串、动态规划、双指针、Manacher 算法
- 本地模式：ACM 标准输入输出

## 题目摘要

给定字符串 `s`，请找出其中最长的回文子串。回文是指正着读和反着读都相同的字符串，子串必须是连续的一段字符。

## 输入描述

输入一行字符串 `s`。字符串仅由数字和英文字母组成。

## 输出描述

输出一个最长回文子串。如果存在多个长度相同的最长回文子串，输出起始位置最小、也就是最早出现的那个。

## 数据范围

- `1 <= len(s) <= 1000`
- `s` 仅由数字和英文字母组成。

## 示例

输入：

```text
babad
```

输出：

```text
bab
```

解释：`aba` 也是长度为 3 的回文子串，但按本地约定输出更早出现的 `bab`。
