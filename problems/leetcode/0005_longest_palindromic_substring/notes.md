## 动态规划重点

这道题使用的是区间动态规划。一个区间是否为回文，取决于它的两个端点是否相等，以及去掉两个端点后的内部区间是否为回文。

### 状态定义

`dp[i][j]` 表示子串 `s[i:j + 1]` 是否为回文串。

### 状态转移

当 `s[i] != s[j]` 时，`s[i:j + 1]` 一定不是回文；当两端相等时：

```python
dp[i][j] = s[i] == s[j] and (j - i <= 1 or dp[i + 1][j - 1])
```

长度为 1 或 2 的子串是基础情况，不需要访问内部状态。

### 初始化与遍历顺序

二维状态表需要创建独立的每一行：

```python
dp = [[False] * n for _ in range(n)]
```

由于 `dp[i][j]` 依赖 `dp[i + 1][j - 1]`，可以让 `i` 从大到小、`j` 从小到大遍历：

```python
for i in range(n - 1, -1, -1):
    for j in range(i, n):
        ...
```

`range(n - 1, -1, -1)` 中的最后一个 `-1` 表示每次减 1；停止位置写成 `-1` 是为了让下标 `0` 也能被遍历到。

### 答案更新

只有当 `dp[i][j]` 为 `True` 时，才能用当前区间更新答案。题目要求相同长度时返回最早出现的回文串；在 `i` 从大到小遍历时，应在长度相等且 `i` 更小时更新，或者直接使用 `>=` 保留后访问到的更小起点。

### 复杂度与易错点

- 时间复杂度：`O(n²)`。
- 空间复杂度：`O(n²)`。
- 子串长度是 `j - i + 1`，不是 `i - j + 1`。
- `dp` 不能初始化为普通空列表后直接访问 `dp[i][j]`。
- 不能使用 `[[False] * n] * n`，否则每一行会引用同一个列表。
