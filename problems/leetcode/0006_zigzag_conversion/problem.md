# 6. Z 字形变换

> 状态：练习中：运行错误。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 6. Z 字形变换](https://leetcode.cn/problems/zigzag-conversion/)
- 难度：中等
- 标签：字符串
- 本地模式：ACM 标准输入输出

## 题目摘要

给定字符串 `s` 和行数 `num_rows`，将字符按从上到下、再从下到上的方向排列成 Z 字形，然后按行读取并输出得到的字符串。

## 输入描述

输入两行：第一行是字符串 `s`，第二行是整数 `num_rows`。

## 输出描述

输出按 Z 字形排列后逐行读取得到的字符串，并换行。

## 数据范围

- `1 <= len(s) <= 1000`
- `s` 由英文字母（大写或小写）、字符 `,` 和 `.` 组成。
- `1 <= num_rows <= 1000`

当 `num_rows` 为 1，或不小于字符串长度时，输出与 `s` 相同。

## 示例

输入：

```text
PAYPALISHIRING
3
```

输出：

```text
PAHNAPLSIIGYIR
```
