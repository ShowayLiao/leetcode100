# LeetCode 17：电话号码的字母组合

## 来源

[LeetCode 17：电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

## 题目摘要

给定一串由数字 `2`–`9` 组成的电话号码，按照电话键盘的字母映射生成所有可能的字母组合。组合中的字符顺序必须与输入数字顺序一致，结果按每个按键上的字母顺序展开。

本地映射如下：

| 数字 | 字母顺序 |
| --- | --- |
| 2 | abc |
| 3 | def |
| 4 | ghi |
| 5 | jkl |
| 6 | mno |
| 7 | pqrs |
| 8 | tuv |
| 9 | wxyz |

## 输入格式

输入一行数字字符串：

- 非空时只包含 `2`–`9`；
- 空行表示空字符串。

## 输出格式

第一行输出组合总数，之后每行输出一个组合。输出顺序遵循电话键盘映射顺序：先展开靠前数字的字母，再展开靠后数字的字母。例如输入 `23` 时，顺序应为 `ad`、`ae`、`af`、`bd`、……、`cf`。

输入为空时只输出一行 `0`，不再输出组合。

## 数据范围与注意事项

本地评测只使用由 `2`–`9` 构成的输入。组合数量等于各数字对应字母数量的乘积，输入较长时结果会快速增长；需要同时关注输出规模和额外空间。
