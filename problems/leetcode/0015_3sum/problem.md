# 15. 三数之和

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 15. 三数之和](https://leetcode.cn/problems/3sum/)
- 难度：中等
- 标签：数组、双指针、排序
- 本地模式：ACM 标准输入输出

## 题目摘要

给定整数数组 `nums`，找出所有和为 `0` 且下标互不相同的三元组。结果中不能包含重复的三元组；每个三元组内部按非递减顺序排列，所有三元组按字典序输出。

## 输入描述

第一行包含整数 `n`，表示数组长度。

第二行包含 `n` 个整数，表示数组 `nums`。

## 输出描述

第一行输出符合条件的三元组数量 `k`。

接下来输出 `k` 行，每行包含三个整数，表示一个三元组。若不存在符合条件的三元组，只输出 `0`。

## 数据范围

- `3 <= n <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 示例

输入：

```text
6
-1 0 1 2 -1 -4
```

输出：

```text
2
-1 -1 2
-1 0 1
```
