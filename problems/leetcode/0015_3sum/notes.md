# 三数之和：解题笔记

## 核心思路

先排序数组，固定第一个数，再用左右指针在其右侧寻找和为 `-nums[index]` 的两个数。和过小时增大左指针，和过大时减小右指针；找到答案后同时移动两个指针。

排序后可以在固定位置和左右指针移动时跳过相同数值，从而避免重复三元组。若固定值已经大于 `0`，后面的数也不可能组成和为 `0` 的答案，可以提前结束。

## 复杂度

- 时间复杂度：`O(n²)`，排序为 `O(n log n)`，双指针枚举为 `O(n²)`。
- 空间复杂度：`O(n)`（Python 排序可能使用辅助空间；不计结果列表）。

## 边界

- 全部为 `0` 时只能输出一个 `(0, 0, 0)`。
- 数组中存在重复值时，固定位置和左右指针都要去重。
- 没有解时输出数量 `0`，不输出额外的三元组行。
