# 8. 字符串转换整数（atoi）

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 8. 字符串转换整数 (atoi)](https://leetcode.cn/problems/string-to-integer-atoi/)
- 难度：中等
- 标签：字符串、模拟
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一行字符串 `s`，按照 `atoi` 规则将其转换为一个 32 位有符号整数。先跳过开头的空格，可选地读取一个 `+` 或 `-` 符号，然后连续读取十进制数字；遇到第一个非数字字符时停止。若开头没有可读取的数字，结果为 `0`。

若解析出的数值超出 32 位有符号整数范围 `[-2^31, 2^31 - 1]`，将结果截断到对应边界。

## 输入描述

输入一整行字符串 `s`。读取时应保留字符串开头的空格，不要将整行内容按空白分隔；空行表示空字符串。输入行中的换行符不属于 `s`。

## 输出描述

输出按照上述 `atoi` 规则解析并截断后的整数。

## 数据范围

- `0 <= len(s) <= 200`
- `s` 可包含英文字母、数字、空格、`+`、`-` 以及 `.`。
- 结果必须落在 `-2147483648` 到 `2147483647` 的闭区间内。

## 示例

输入：

```text
   -42abc
```

输出：

```text
-42
```

解释：跳过开头空格并读取负号和数字 `42`，遇到字母 `a` 后停止。
