# 快速排序：解题笔记

## 核心思路

选取区间中的一个元素作为基准，通过一次分区把数组分成三部分：小于基准、等于基准、大于基准；再递归处理左右两部分。

使用三路分区可以让大量重复元素快速归并到中间区域。递归较小的区间、循环处理较大的区间，可以把额外栈空间控制在 `O(log n)` 级别。

## 复杂度

- 平均时间复杂度：`O(n log n)`。
- 最坏时间复杂度：`O(n^2)`。
- 额外空间复杂度：平均递归栈为 `O(log n)`。

## 易错点

- 分区过程中，从右侧换入的新元素还没有检查，不能在交换后直接无条件右移扫描指针。
- 递归区间必须排除已经归入“等于基准”的部分。
- 不要用 Python 内置排序函数替代快速排序练习。
