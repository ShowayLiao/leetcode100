# 912. 快速排序（排序数组）

- 本地模式：ACM 标准输入输出

本题将原题改写为本仓库使用的 ACM 输入输出协议，并额外要求手写快速排序。

## 题目摘要

给定一个整数数组，请将数组按升序排列并输出。

本题用于练习快速排序。解答必须自己实现快速排序的分区和递归（或等价的非递归）过程，不能调用 Python 的 `sort()` 或 `sorted()`。

## 输入描述

第一行包含一个整数 `n`，表示数组长度。

第二行包含 `n` 个整数，表示数组元素。

## 输出描述

输出一行 `n` 个整数，表示升序排列后的数组，整数之间用一个空格分隔。

## 数据范围（本地练习约束）

- `1 <= n <= 100000`
- `-10^9 <= nums[i] <= 10^9`

## 示例

输入：

```text
6
5 2 9 1 5 6
```

输出：

```text
1 2 5 5 6 9
```

## 练习要求

- 不得调用 `sort()`、`sorted()` 或其他现成排序函数。
- 分区后，基准值左侧的元素不大于基准值，右侧的元素不小于基准值。
- 注意处理重复元素、负数、已经有序和逆序数组。
