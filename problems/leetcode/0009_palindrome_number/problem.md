# 9. 回文数

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 9. 回文数](https://leetcode.cn/problems/palindrome-number/)
- 难度：简单
- 标签：数学、双指针
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个 32 位有符号整数 `x`，判断它的十进制表示是否正着读、反着读都相同。负数不视为回文数。

## 输入描述

输入一行整数 `x`。

## 输出描述

如果 `x` 是回文数，输出 `true`；否则输出 `false`。输出必须使用小写英文单词并换行。

## 数据范围

- `-2^31 <= x <= 2^31 - 1`

## 示例

输入：

```text
121
```

输出：

```text
true
```
