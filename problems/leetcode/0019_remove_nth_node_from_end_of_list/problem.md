# 19. 删除链表的倒数第 N 个结点

> 状态：未实现。验证日期：2026-10-08；仅代表当前本地用例。

- 难度：中等
- 标签：链表、双指针

- 来源：[LeetCode 19. Remove Nth Node From End of List](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个单链表和一个倒数位置 `k`，删除链表中倒数第 `k` 个结点，并输出删除后的链表。

本练习使用整数序列表示链表，学习者需要自行完成链表删除逻辑。题目重点是正确处理删除头结点、尾结点以及删除后链表为空的情况。

## 输入描述

输入共三行：

1. 第一行是整数 `n`，表示链表长度。
2. 第二行包含 `n` 个整数，按从头到尾的顺序表示链表结点值。
3. 第三行是整数 `k`，表示要删除的倒数位置；倒数第一个结点的 `k` 为 `1`。

## 输出描述

输出删除后的链表结点值，按原顺序以空格分隔，并在末尾换行。

如果删除后链表为空，输出空行。

## 数据范围

- `1 <= n <= 30`
- `1 <= k <= n`
- 结点值为整数。
