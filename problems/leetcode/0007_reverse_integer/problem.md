# 7. 整数反转

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 7. 整数反转](https://leetcode.cn/problems/reverse-integer/)
- 难度：中等
- 标签：数学
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个带符号的 32 位整数 `x`，返回将其十进制数字顺序反转后的整数。反转结果超出 32 位有符号整数范围时，输出 `0`。

反转后整数的十进制表示不保留无意义的前导零；负数的符号仍位于数字最前方。

## 输入描述

输入一行整数 `x`。

## 输出描述

输出反转后的整数；如果结果不在 32 位有符号整数范围内，输出 `0`。

## 数据范围

- `-2^31 <= x <= 2^31 - 1`
- 结果必须满足 `-2^31 <= result <= 2^31 - 1`，否则按规则输出 `0`。

## 示例

输入：

```text
123
```

输出：

```text
321
```
