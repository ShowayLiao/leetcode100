# 最接近的三数之和：解题笔记

## 思路提示

- 可以先排序数组，再固定一个数，把剩余区间交给左右指针搜索。
- 每次比较当前和与 `target` 的距离，并维护目前最好的候选和。
- 排序后，当前和偏小时增大左指针，偏大时减小右指针。
- 距离相同时要比较候选和本身，保留较小值。

## 复杂度

- 时间复杂度：`O(n^2)`，其中排序为 `O(n log n)`。
- 空间复杂度：`O(n)`，主要考虑排序所需的辅助空间。

## 错误与边界

- `n = 3` 时只有一个合法三元组，不能遗漏这种边界。
- 重复值仍然可以来自不同下标；求最近和时不能简单按数值去重。
- 两个候选和与 `target` 等距时，必须选择较小的和。
