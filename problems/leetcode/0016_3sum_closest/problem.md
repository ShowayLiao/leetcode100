# 16. 最接近的三数之和

- 来源：[LeetCode 16. 最接近的三数之和](https://leetcode.cn/problems/3sum-closest/)
- 难度：中等
- 标签：数组、排序、双指针
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个整数数组，从不同下标位置选出三个数，使它们的和与 `target` 的绝对差最小。输出这个三数之和；如果有多个和距离相同，输出较小的和。

## 输入描述

第一行包含两个整数 `n` 和 `target`，分别表示数组长度和目标值。

第二行包含 `n` 个整数，表示数组 `nums`。

## 输出描述

输出一个整数，表示距离 `target` 最近的三数之和。

## 数据范围

- `3 <= n <= 1000`
- `-1000 <= nums[i] <= 1000`
- `-10^4 <= target <= 10^4`
- 保证至少可以从数组中选出三个数。
