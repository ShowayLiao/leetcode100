# 1. 两数之和

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 1. 两数之和](https://leetcode.cn/problems/two-sum/)
- 难度：简单
- 标签：数组、哈希表
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个整数数组和目标值，寻找两个不同元素，使它们的和等于目标值，输出这两个元素的零基下标。

## 输入描述

第一行包含两个整数 `n` 和 `target`，分别表示数组长度和目标值。

第二行包含 `n` 个整数，表示数组 `nums`。

## 输出描述

按升序输出两个符合条件的零基下标，中间用一个空格分隔。

## 数据范围

- `2 <= n <= 10^4`
- `-10^9 <= nums[i], target <= 10^9`
- 保证恰好存在一组答案。
- 同一个元素不能重复使用。

## 样例

输入：

```text
4 9
2 7 11 15
```

输出：

```text
0 1
```
