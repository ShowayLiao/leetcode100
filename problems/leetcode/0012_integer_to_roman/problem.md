# 12. 整数转罗马数字

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 12. 整数转罗马数字](https://leetcode.cn/problems/integer-to-roman/)
- 难度：中等
- 标签：哈希表、数学、字符串、贪心
- 本地模式：ACM 标准输入输出

## 题目摘要

给定一个整数 `num`，将它转换为罗马数字。采用标准罗马数字表示法，其中 `I`、`V`、`X`、`L`、`C`、`D`、`M` 分别表示 `1`、`5`、`10`、`50`、`100`、`500`、`1000`。

需要正确处理 `IV`、`IX`、`XL`、`XC`、`CD` 和 `CM` 等减法表示。

## 输入描述

输入一行整数 `num`。

## 输出描述

输出 `num` 的标准罗马数字表示，并换行。

## 数据范围

- `1 <= num <= 3999`

## 示例

输入：

```text
1994
```

输出：

```text
MCMXCIV
```
