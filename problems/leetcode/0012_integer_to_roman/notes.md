# 整数转罗马数字：解题笔记

## 核心思路

把普通数值和标准罗马数字片段按从大到小排列，包含 `900`、`400` 等特殊组合。依次用当前数值整除每个单位，追加对应次数的符号，再把余数交给更小的单位处理。

## 复杂度

- 时间复杂度：`O(1)`，单位表长度固定。
- 空间复杂度：`O(1)`，不计输出字符串。

## 边界

- `4`、`9`、`40`、`90`、`400`、`900` 必须使用减法表示。
- `1` 和 `3999` 分别测试最小值与最大值。
- 处理完一个单位后继续使用余数，避免遗漏低位数字。

## 罗马数字的用法

- 基本符号：`I=1`、`V=5`、`X=10`、`L=50`、`C=100`、`D=500`、`M=1000`。
- 通常从左到右相加，例如 `VIII = 5 + 1 + 1 + 1 = 8`。
- 小数值写在大数值前表示相减，但标准写法只有：`IV`、`IX`、`XL`、`XC`、`CD`、`CM`。
- 同一个符号通常最多连续出现三次，`V`、`L`、`D` 不重复使用。
- 例如：`3200 = MMMCC`，`1994 = MCMXCIV`。
