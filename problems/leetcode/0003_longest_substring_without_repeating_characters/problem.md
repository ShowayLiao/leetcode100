# 3. 无重复字符的最长子串

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)
- 难度：中等
- 标签：哈希表、字符串、滑动窗口
- 本地模式：ACM 标准输入输出

## 题目摘要

给定字符串 `s`，请找出其中不含重复字符的最长子串，并输出它的长度。子串必须是连续的一段字符，不能把不连续的字符拼接起来。

## 输入描述

输入一行字符串 `s`。字符串可以包含英文字母、数字、符号和空格。空字符串用空行表示，输入中的空格属于字符串内容，不能被自动删除。

## 输出描述

输出一个整数，表示最长无重复字符子串的长度。

## 数据范围

- `0 <= len(s) <= 10^5`
- `s` 由英文字母、数字、符号和空格组成。

## 示例

输入：

```text
abcabcbb
```

输出：

```text
3
```

解释：最长无重复字符子串可以是 `abc`、`bca` 或 `cab`。
