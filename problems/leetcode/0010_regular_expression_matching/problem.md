# 10. 正则表达式匹配

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 10. 正则表达式匹配](https://leetcode.cn/problems/regular-expression-matching/)
- 难度：困难
- 标签：字符串、动态规划、递归、记忆化搜索
- 本地模式：ACM 标准输入输出

## 题目摘要

给定字符串 `s` 和模式 `p`，判断模式是否能够匹配整个字符串。模式只包含小写英文字母、`.` 和 `*`：`.` 匹配任意一个字符，`*` 表示它前面的元素可以出现零次或多次。

## 输入描述

输入两行：第一行是字符串 `s`，第二行是模式 `p`。输入不包含换行符，不把行尾换行符作为内容。

## 输出描述

如果 `p` 能完整匹配 `s`，输出 `true`；否则输出 `false`。输出必须使用小写英文单词并换行。

## 数据范围

- `1 <= len(s) <= 20`
- `1 <= len(p) <= 20`
- `s` 只包含小写英文字母。
- `p` 只包含小写英文字母、`.` 和 `*`，且 `*` 总是位于一个有效元素之后。

## 示例

输入：

```text
aab
c*a*b
```

输出：

```text
true
```
