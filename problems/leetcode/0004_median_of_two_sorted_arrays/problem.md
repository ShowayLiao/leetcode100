# 4. 寻找两个正序数组的中位数

> 状态：本地用例通过。验证日期：2026-10-08；仅代表当前本地用例。

- 来源：[LeetCode 4. 寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/)
- 难度：困难
- 标签：数组、二分查找、分治
- 本地模式：ACM 标准输入输出

## 题目摘要

给定两个从小到大排列的数组 `nums1` 和 `nums2`，请找出合并后有序数组的中位数。目标算法的时间复杂度应为 `O(log(m+n))`。

## 输入描述

第一行包含两个整数 `m` 和 `n`，分别表示两个数组的长度。

第二行包含 `m` 个整数，表示有序数组 `nums1`。第三行包含 `n` 个整数，表示有序数组 `nums2`。当某个数组长度为 `0` 时，对应输入行为空行。

## 输出描述

输出中位数，并固定保留 5 位小数。

## 数据范围

- `0 <= m, n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`
- 两个数组均按非递减顺序排列。

## 示例

输入：

```text
2 2
1 2
3 4
```

输出：

```text
2.50000
```

解释：合并数组为 `[1, 2, 3, 4]`，中位数为 `(2 + 3) / 2 = 2.5`。
