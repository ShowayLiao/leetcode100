## 题目概述

给定一个整数数组 `nums` 和目标值 `target`，从数组中选择四个不同下标的元素，使它们的和等于 `target`。需要找出所有满足条件的四元组。

每个四元组内部按非递减顺序排列；数值完全相同的四元组只保留一次。所有四元组按字典序排列。

## 输入格式

- 第一行包含两个整数 `n target`。
- 第二行包含 `n` 个整数，表示数组 `nums`。

本地测试保证第二行与 `n` 匹配；当 `n` 小于 4 时可直接判定无解。

## 输出格式

- 有解时，第一行输出不重复四元组的数量 `k`，随后输出 `k` 行，每行包含一个按非递减顺序排列的四元组。
- 没有解时只输出一行 `0`。

输出中的四元组必须按字典序排列，不额外输出下标或其他说明文字。

## 数据范围

- `0 <= n <= 200`
- `-10^9 <= nums[i], target <= 10^9`
