# 四数之和：学习笔记

## 思路提示

- 先排序，便于判断剩余和的方向，也便于统一处理重复值。
- 可以固定前两个数，把后两个数转化为有序区间上的双指针查找。
- 找到一个解后，要跳过相同的首数、次首数和双指针位置，避免输出重复四元组。
- 结果天然按排序后的枚举顺序组织；仍需检查输出时的字典序要求。

## 复杂度记录

- 主要循环通常为 `O(n^3)` 时间。
- 排序外的额外空间取决于结果数量；若只计算辅助空间，应单独记录排序和双指针所需空间。

## 边界与自检

- 四个元素必须来自四个不同下标，即使它们的数值相同也要确认出现次数足够。
- 重点检查全是重复值、没有解、多个解，以及负数和大绝对值混合的情况。
- Python 的整数不会溢出，但仍要保证输入解析、结果去重和输出格式准确。
