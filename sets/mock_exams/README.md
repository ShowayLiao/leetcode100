# 模拟考试

一场模拟考试通过相对链接组合 2 至 5 道已经存在于 `problems/` 的题目，不复制代码。

## 场次记录格式

```markdown
# 公司或主题 YYYY-MM-DD

- 总时长：120 分钟
- 开始时间：YYYY-MM-DD HH:MM
- 结束时间：YYYY-MM-DD HH:MM
- 规则：不查看题解，只使用本地编辑器和终端。

| 顺序 | 题目 | 计划用时 | 实际结果 | 复盘 |
|---:|---|---:|---|---|
```

模拟期间 Codex 只负责计时提醒和题意澄清，不提供算法提示。模拟结束后，再让 Codex 运行测试、构造边界用例并协助复盘。
