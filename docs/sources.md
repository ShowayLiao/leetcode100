# 来源与使用说明

本仓库用于个人 Python ACM 学习。各题 `problem.md` 保存原题链接、个人题意摘要和本地输入输出协议，解答和笔记包含不同完成阶段的个人练习。

- Hot 100 范围以 [本地题单](../sets/leetcode_hot100.md)为准，其中保留原始题单及分类参考链接。
- 同一题目的历史目录与 Hot 100 目录代表不同练习，不按是否完成而删除历史尝试。
- 不收录未经明确许可的第三方完整题面、批量题解或公司保密试题。
- 本地协议可能增加输出顺序、构造规则或允许的空输入，以本题文档为准。
- 当前未选择开源许可证；第三方题目、商标及引用资料不因本仓库发布而改变权利归属。

## 工具配置参考

CI 使用 GitHub 官方 [checkout](https://github.com/actions/checkout) 与 [setup-python](https://github.com/actions/setup-python)，安装指定 Python 版本并运行本地检查；没有额外的 Python 依赖。
