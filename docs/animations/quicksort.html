读这段代码时，记住三件事

右侧换入后 current 不动：nums[greater] 原本属于未知区域，换过来的值必须重新检查。

左侧换入后 current 可以前进：less < current 时，nums[less] 已知等于基准；两指针相同时只是自身交换。

基准是保存的值：代码选中间位置的元素值，它不一定是中位数。分区平均耗时 O(n)，整体平均 O(n log n)、最坏 O(n²)；短段递归让栈空间保持 O(log n)。
