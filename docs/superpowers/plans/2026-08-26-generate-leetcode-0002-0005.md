# LeetCode 0002～0005 题目目录生成计划

## 目标

按照 `problems/leetcode/0001_two_sum/` 的 ACM 练习目录结构，创建 LeetCode 2～5 的题目目录。每个目录包含题目输入输出契约、笔记模板、成对的本地测试文件，以及保持为空的 `main.py`。

## 目录与文件

- `problems/leetcode/0002_add_two_numbers/`
  - `problem.md`：两数相加的 ACM 链表序列化约定、来源链接、约束和示例。
  - `notes.md`：解题观察、思路、复杂度和边界记录模板。
  - `main.py`：空文件，留给练习实现。
  - `tests/01.in`、`tests/01.out` 等：覆盖普通进位、零值和连续进位。
- `problems/leetcode/0003_longest_substring_without_repeating_characters/`
  - `problem.md`：单行字符串输入和长度输出约定。
  - `notes.md`：滑动窗口相关的解题记录模板。
  - `main.py`：空文件。
  - `tests/01.in`、`tests/01.out` 等：覆盖重复字符、全重复和一般窗口移动。
- `problems/leetcode/0004_median_of_two_sorted_arrays/`
  - `problem.md`：两个有序数组的 ACM 输入约定和固定五位小数输出约定。
  - `notes.md`：二分切分相关的解题记录模板。
  - `main.py`：空文件。
  - `tests/01.in`、`tests/01.out` 等：覆盖奇数总长度、偶数总长度和空数组。
- `problems/leetcode/0005_longest_palindromic_substring/`
  - `problem.md`：单行字符串输入、最长回文子串输出，以及多解时取最早起点的约定。
  - `notes.md`：中心扩展或动态规划相关的解题记录模板。
  - `main.py`：空文件。
  - `tests/01.in`、`tests/01.out` 等：覆盖奇数回文、偶数回文和单字符。

## 验证

1. 检查四个目录都包含约定文件。
2. 检查四个 `main.py` 的文件大小均为 0 字节。
3. 检查每个 `.in` 都存在同名 `.out`。
4. 不运行题目测试作为通过判断，因为用户明确要求 `main.py` 留空；测试文件仅作为后续实现的基准。
