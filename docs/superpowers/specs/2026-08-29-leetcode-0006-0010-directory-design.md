# LeetCode 0006–0010 目录设计

## 目标与范围

保留现有 `problems/leetcode/0005_longest_palindromic_substring/` 及其中的学习者实现，不修改现有题目、题单索引或仓库工具。新增 LeetCode 0006–0010 五个 ACM 练习目录：

- `0006_zigzag_conversion`
- `0007_reverse_integer`
- `0008_string_to_integer_atoi`
- `0009_palindrome_number`
- `0010_regular_expression_matching`

## 统一目录约定

每道题包含以下内容：

- `problem.md`：原题链接、难度、标签、简要题意、明确的 ACM 输入输出契约、约束和一个示例。
- `notes.md`：仅提供观察、思路记录、复杂度和边界情况等填写位置，不包含完整实现。
- `main.py`：保持 0 字节，留给学习者独立完成。
- `tests/`：至少三组成对的 `NN.in` 与 `NN.out`，覆盖典型情况和关键边界。

题面只保留个人总结与必要契约，不批量复制 LeetCode 完整题面或他人题解。

## 各题 ACM 契约

### 0006 字形变换

- 输入：第一行是字符串 `s`，第二行是行数 `num_rows`。
- 输出：按指定行数进行 Z 字形排列后，逐行读取所得的字符串。
- 测试重点：常规多行、两行、只有一行。

### 0007 整数反转

- 输入：一个 32 位有符号整数 `x`。
- 输出：十进制数字反转后的整数；结果超出 32 位有符号整数范围时输出 `0`。
- 测试重点：正数末尾有零、负数、反转后溢出。

### 0008 字符串转换整数

- 输入：一整行字符串 `s`，保留开头空格；空行表示空字符串。
- 输出：按照原题 `atoi` 规则解析并截断到 32 位有符号整数范围后的整数。
- 测试重点：前导空格和符号、遇到非数字停止、上下界截断。

### 0009 回文数

- 输入：一个 32 位有符号整数 `x`。
- 输出：若 `x` 的十进制表示是回文，输出 `true`；否则输出 `false`。
- 测试重点：普通回文、负数、末尾为零的非零整数。

### 0010 正则表达式匹配

- 输入：第一行是字符串 `s`，第二行是模式 `p`。
- 输出：若模式可以匹配整个字符串，输出 `true`；否则输出 `false`。
- 模式语义：`.` 匹配任意单个字符，`*` 表示其前一个元素可以出现零次或多次。
- 测试重点：直接不匹配、`*` 匹配多次、组合模式覆盖整个字符串。

## 验证标准

1. 五个目录均遵循四位题号与小写下划线 slug 约定。
2. 每个目录都具有 `problem.md`、`notes.md`、0 字节 `main.py` 和 `tests/`。
3. 每个输入文件都有同名输出文件，且测试期望符合该题的本地 ACM 契约。
4. 因 `main.py` 按要求留空，不以运行题目测试作为本批目录创建成功的判据；改为验证目录结构、文件大小和测试配对。
5. 不改动 0005 及其他既有学习内容。
