## ACM 输入输出契约

### 0016 3Sum Closest

- 输入：第一行 `n target`，第二行 `n` 个整数。
- 输出：与 `target` 差的绝对值最小的三数之和；若出现同样近的结果，取较小的和，以保证 ACM 输出确定。
- 测试重点：普通命中、负数、重复值和三元素最小规模。

### 0017 Letter Combinations of a Phone Number

- 输入：一行只含数字 `2`–`9` 的字符串；空行表示空字符串。
- 输出：第一行组合数量，随后按电话键盘映射顺序逐行输出组合；空字符串只输出 `0`。
- 测试重点：两位数字、单个数字和空输入。

### 0018 4Sum

- 输入：第一行 `n target`，第二行 `n` 个整数。
- 输出：第一行满足条件的四元组数量，随后逐行输出升序四元组；四元组按字典序排列且不重复；无解只输出 `0`。
- 测试重点：典型样例、重复元素、无解和多组结果。

### 0019 Remove Nth Node From End of List

- 输入：第一行链表长度 `n`，第二行 `n` 个整数，第三行待删除的倒数位置 `k`。
- 输出：删除节点后的链表，元素以空格分隔并换行；删除后为空时输出空行。
- 测试重点：删除中间节点、删除头节点、单节点链表和删除尾节点。

### 0020 Valid Parentheses

- 输入：一行括号字符串；空行表示空字符串。
- 输出：括号序列有效输出 `true`，否则输出 `false`。
- 测试重点：三类括号匹配、交叉嵌套、孤立右括号和空字符串。

## 验证标准

1. 五个目录均有统一的四类文件和至少三组 `.in`/`.out` 测试对。
2. 测试文件严格匹配各题的本地 ACM 契约，覆盖典型场景与关键边界。
3. 不修改已有题目、仓库工具和题目集合索引。
4. 空 `main.py` 的本地运行结果只用于确认测试契约存在，不作为题目解法通过依据。
