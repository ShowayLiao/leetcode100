# LeetCode 0002～0005 目录设计

## 范围

为 LeetCode 2～5 创建与 `0001_two_sum` 一致的 ACM 练习目录。每道题包含题目说明、笔记模板、空的 `main.py` 和本地输入输出测试。

## 统一约定

- 目录使用四位题号加英文小写下划线 slug。
- `problem.md` 只保留题意摘要、ACM 输入输出契约、约束、示例和官方来源链接。
- `notes.md` 提供观察、思路、复杂度和边界记录位置，不预先写实现代码。
- `main.py` 保持 0 字节，交由练习者实现。
- 测试采用 `tests/NN.in` 与 `tests/NN.out` 配对格式。

## 题目特定约定

- 0002 将链表按题目中的逆序数字序列输入，输出结果链表长度和数字序列。
- 0003 输入整行字符串，输出最长无重复子串长度；输入中的空格属于字符串内容。
- 0004 输入两个有序数组，输出中位数并固定保留 5 位小数；允许其中一个数组为空。
- 0005 输入一行字符串，输出最长回文子串；多个同长答案时取起始位置更小的答案。
