# 收藏与二刷清单设计

## 目标

为刷题仓库增加一个集中维护的 Markdown 复习清单。用户通过自然语言告知 Codex 收藏、取消收藏或完成二刷，Codex 负责更新清单，用户无需手动编辑。

## 文件与职责

- `sets/review.md`：保存所有来源题目的收藏和二刷记录，作为唯一数据源。
- `AGENTS.md`：定义 Codex 处理收藏、取消收藏和二刷指令时必须遵循的工作流。

不把收藏信息写入 `sets/leetcode_hot100.md`，避免复习清单被限制在 Hot 100；不与 `notes/mistakes.md` 合并，避免混淆“值得二刷”和“已经做错”两种含义。

## 清单格式

`sets/review.md` 使用 Markdown 表格，每道题一行：

```markdown
# 收藏与二刷清单

| 收藏日期 | 题目与复习入口 | 收藏原因 | 二刷次数 |
|---|---|---|---:|
| 2026-08-26 | [题目](../../../problems/leetcode/0002_add_two_numbers/problem.md) · [代码](../../../problems/leetcode/0002_add_two_numbers/main.py) · [笔记](../../../problems/leetcode/0002_add_two_numbers/notes.md) | 逐位相加、进位处理与序列解包 | 0 |
```

字段规则：

- 收藏日期使用 `YYYY-MM-DD`，记录首次收藏日期。
- 题目入口同时链接 `problem.md`、`main.py` 和 `notes.md`。
- 收藏原因优先采用用户给出的文字；用户未说明时，Codex 根据当前对话提炼一句可迁移的复习重点。
- 二刷次数为非负整数，首次收藏记为 `0`。

## 更新工作流

- 用户说“收藏这题”或同义表达时，Codex 根据当前题目新增一行。
- 同一道题已经存在时不新增重复行；若用户给出新的收藏原因，则更新原因，同时保留首次收藏日期和已有二刷次数。
- 用户说“完成一次二刷”或同义表达时，对应题目的二刷次数增加 `1`。
- 用户说“取消收藏”或同义表达时，删除对应行。
- 新收藏按收藏日期降序排列；同一天按题号升序排列。
- 题目身份以规范化的本地题目目录路径为准，不以显示名称判断，避免同名题目冲突。

## 验证

每次更新清单后执行以下检查：

1. Markdown 表格列数一致，二刷次数是非负整数。
2. 同一规范化题目目录只出现一次。
3. 每个相对链接指向现有的 `problem.md`、`main.py` 或 `notes.md`。
4. 收藏、二刷或取消操作只修改目标题目的记录，不改动解题代码。
